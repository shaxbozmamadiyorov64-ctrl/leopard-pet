# 🐆 Leopard Pet — виртуальный питомец

Интерактивный 3D-леопард, который живёт на экране телефона и меняет настроение в зависимости от заряда батареи.
Это веб-прототип (один файл `index.html`, three.js). Нативная версия для Android — следующий этап.

## Возможности

- **3D-леопард** с золотистой шерстью и чёрными розетками, прозрачный фон.
- **Анимации:** ходит, лежит, спит, потягивается, умывается лапой, зевает, смотрит по сторонам, двигает ушами и хвостом.
- **Касания:** голова, хвост, лапа и тело реагируют по-разному; поглаживание — мурлыканье.
- **Батарея** (реальный заряд через Battery API, либо симуляция):

| Заряд | Поведение |
|---|---|
| 80–100% | активный, игривый, довольный |
| 50–79% | спокойный, гуляет, ухаживает за шерстью |
| 21–49% | усталый, чаще лежит и зевает |
| 20% | сцена: над леопардом кружат совы |
| 10% и ниже | приходит медведь на каждый −1% (сцены не накладываются) |
| 1–5% | сонный, засыпает |

- **Зарядка:** леопард замечает подключение, бодреет; при 20% совы улетают; при 100% — особая радостная сцена.
- **Характер:** 7 состояний (спокойствие, любопытство, радость, игривость, усталость, настороженность, сон), «доверие» растёт от поглаживаний и сохраняется в `localStorage`.
- **Чат** (двойное касание): офлайн-словарь EN → UZ без ИИ. Иногда леопард сам спрашивает по настроению: *«Sen nima qilyapsan?»* («Чем ты занят?»).
- **Настройки:** звуки, громкость, частота анимаций, симуляция батареи.

## Запуск

Откройте `index.html` в браузере. Для GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.

> Реальный заряд читается через [Battery API](https://developer.mozilla.org/docs/Web/API/Battery_Status_API) — он работает в Chrome на Android. В других браузерах автоматически включается симуляция (⚙ → ползунок заряда).

## Ограничения

- Показ поверх других приложений в браузере невозможен. В нативном Android-приложении это делается через `SYSTEM_ALERT_WINDOW` с запросом разрешения у пользователя.
- Непрерывная фоновая анимация зависит от ограничений Android на фоновую работу.
- Модель процедурная (из примитивов). Для более высокого реализма можно подключить готовую glTF-модель.
